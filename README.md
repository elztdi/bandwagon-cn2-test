## 怎么测才有参考价值？三步走

### 第一步：本地 ping 测延迟

Windows 打开 cmd，输入：


ping 162.244.241.102


把 IP 换成你想测的机房地址。看平均延迟和丢包率。

- 电信用户洛杉矶方向：延迟大概在 150-180ms 算正常，低于 150ms 算好
- 香港机房：30-60ms 都是正常范围

### 第二步：全国 ping 测多地延迟

单点 ping 只能代表你这一个地点。建议去 `ping.chinaz.com` 输入测试 IP，看全国各地节点的延迟分布。北方用户偶尔会发现南方机房延迟比预期低，这时候迁机房就值了。

### 第三步：下载文件或用演示站测速

1. 打开对应机房的演示站（dc6.bwg.net / dc9.bwg.net 等）
2. 用 SpeedTest 测上传下载
3. 用 LookingGlass 做路由追踪，看回程走的是不是 59.43.x.x 开头的电信 CN2 GIA 骨干

路由追踪能直观看到数据包经过的节点。晚高峰时段重新测一次——如果延迟涨幅不大，说明这个机房晚高峰稳定性不错。
